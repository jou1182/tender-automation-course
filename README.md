# 🏗️ نظام أتمتة المناقصات الذكي — المستودع التعليمي

> نظام متكامل لمراقبة وأتمتة متابعة المناقصات الحكومية: سحب آلي + محرك مقارنة ذكي + بوت تليجرام تفاعلي + لوحة ويب + مساعد ذكاء اصطناعي.
> **مستودع تعليمي مرافق لدورة تدريبية** — نسخة معمّمة نظيفة، بلا أي بيانات أو أسرار حقيقية.

---

## ✨ ماذا يفعل النظام؟

- 🔍 **يسحب** المنافسات من منصة الشركة تلقائياً كل 5 دقائق
- 🧠 **يقارن** بذكاء (منع تكرار عربي متقدّم) — يكتشف الجديد وتعديلات المواعيد
- 📱 **يُشعر** عبر تليجرام مع أزرار اعتماد تفاعلية
- 🖥️ **يعرض** لوحة ويب متجاوبة (متابعة + تحليلات + سجل نتائج)
- 🤖 **يجيب** عبر مساعد GPT بالعربية عن بيانات النظام
- 🛡️ **يحرس نفسه** (حارس ذاتي + نسخ احتياطي مُدقّق + نبض عميق)

---

## 🚀 البدء السريع

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# حرّر company_profile.json بهوية شركتك
cp .env.example .env            # ثم املأ الأسرار

python provision_instance.py    # قاعدة بيانات نظيفة
python tests/run_all.py         # بوابة الجودة
python web_dashboard.py         # اللوحة
python bot_daemon.py            # البوت
```

## 🔒 ملاحظة أمنية

هذا المستودع **معمّم تماماً**: لا توكنات، لا كلمات مرور، لا بيانات شركة حقيقية. كل الأسرار تُقرأ من `.env` (المستبعد عبر `.gitignore`). **لا تضع أسراراً حقيقية في أي ملف يُرفع.**
